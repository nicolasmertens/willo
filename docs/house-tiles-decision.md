# House tiles (liedjes)

Locked 2026-08-17 after papa felt right and Nick said save this as the style.

## Look

Graphic poster, crocodile is the lead. Flat field, one huge subject, no text, no merch, no YouTube thumb. Overflow is 12px on 1–2 sides, never into a neighbor gap.

## What a tile names

William taps a **thing he can name**, not a show he has seen. Parent tab already picks the language.

| Case | Icon |
|---|---|
| Same song across papa / mama / klas | **Same asset** (bus, ABC, shark, one little finger) |
| Free translation with a different protagonist | **Different** subject, same house (beetle ≠ spider) |
| Same animal, different song | **Different** (papa side-snout croc ≠ mama front-grin “gros crocodiles”) |
| Two recordings on one tab | Distinct only if he must pick a version (klas Old Mac 09 vs 11). Otherwise one icon. |

TV / YouTube: keep the **subject** (red bus, pink-dress girl, a shark). Drop the **packaging** (Cocomelon still, Pinkfong, burned-in lyrics).
