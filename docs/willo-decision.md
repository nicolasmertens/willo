# Willo (liedjes PWA)

Brand: **Willo**. Icon pixels: William’s face, no word. iOS label: Willo.

Public URL: `https://nicolasmertens.github.io/willo/`. Languages stay `/mama/`, `/papa/`, `/klas/`.

Settings live on this device. Long-press Stop (2s, fires on the timer in Safari) + 4-digit PIN. Languages, sections, per-tile toggles, birth date (Lovevery month buckets), face photos, export/import.

No App Store. Sister gets a clean Add-to-Home-Screen. Delete icon = fresh unless they import the backup file.
